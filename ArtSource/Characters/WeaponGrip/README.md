# Equipped sword grip and airborne pose

The sword Root bone is translated Z=-11.237671 cm. Its usable wrapped handle spans approximately component Z=-4 to +6 cm, with center Z=+1 cm. `Tools/Unreal/fix_sword_grip_socket.py` sets Root-local `HandGrip` Z=12.237671 cm, yielding that component-space center. The original 11.953986 cm was already near the center; the primary original defect was the open hand pose. A transient Z=0 socket experiment incorrectly ignored the Root translation and was corrected. The character hand socket is unchanged.

`verify_grip.py` loads the authored body and the actual sword exported from Unreal. It reproduces the reference-space finger rotations and thumb target, then renders `grip_palm.jpg` and `grip_back.jpg`. The generated `GripValidation.blend` is an inspection scene, not a replacement character asset. These closeups show the underlying low-poly skin geometry without game lighting. The FBX is an export of the existing project sword, not a new third-party asset.

Runtime `UFableWeaponPoseMeshComponent` retains the locomotion animation graph. While the iron sword is equipped, it blends the right fingers toward a closed grip. In the air, a two-bone correction holds the right arm outside the torso with the blade pointing upward and outward. Corrections run on the completed editable component-space pose before Unreal publishes/flips its transform buffers, so socket attachments and leader-pose armor receive the same result. Ragdoll physics skips the correction. Unequipped poses are untouched after the short blend-out.

`FableForge.Character.EquippedSwordPose` samples 21 phases of the actual jump sequence on both body meshes. It checks unchanged unarmed/unrelated bones, finite normalized transforms, preserved bone lengths during blends, and a fully corrected airborne blade outside a conservative torso envelope. This envelope test is not a triangle-level collision proof for every character morph or intermediate equip transition.
